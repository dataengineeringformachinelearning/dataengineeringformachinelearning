# Keyboard shortcuts

Suite power-user chords (⌘K, `/`, undo/redo, **`?`** help, **⌘,**/`Ctrl+,`
preferences) are documented in the FORJD repository:

- Canonical: [FORJD `docs/KEYBOARD_SHORTCUTS.md`](https://github.com/dataengineeringformachinelearning/forjd/blob/main/docs/KEYBOARD_SHORTCUTS.md)
- Decision: FORJD ADR-0023

DEML consumes the same dual-adapter helpers from Viking-UI
(`createShortcutRegistry`, `viking-shortcut-help`). Press **`?`** on deml.app
(outside a text field) to open the in-app reference.
